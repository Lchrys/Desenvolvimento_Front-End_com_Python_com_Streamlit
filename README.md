## 💻 Desenvolvimento Front-End com Python (Streamlit)

Este repositório reúne os projetos e trabalhos desenvolvidos durante minha graduação em Tecnologia em Ciência de Dados e Inteligência Artificial, pelo Instituto Infnet.

O conteúdo apresentado foi elaborado no contexto da disciplina Desenvolvimento Front-End com Python (Streamlit), integrante do Bloco de Inteligência Artificial Aplicada [26E3_5].

O objetivo deste portfólio é organizar e compartilhar publicamente essas experiências acadêmicas, de forma transparente e acessível.

Todos os projetos foram previamente avaliados por professores e monitores do Instituto Infnet, garantindo sua qualidade.
